# PHP Developer (0–2 Years) — Web Application Maintenance

**Location:** New Delhi (Onsite)
**Employment type:** Full-time
**Experience:** 0–2 years

## About the role

We're hiring a PHP Developer to join our team and help maintain and improve our scholarship management web portal — a live application built on PHP and CodeIgniter, used by administrators, universities, and applicants for scholarship application workflows and reporting.

This is a great opportunity for someone early in their career to work on a real, actively-used production system — fixing bugs, building features, and learning how a live web application is maintained, secured, and improved over time, under the guidance of senior developers.

## What you'll be doing

- Writing and maintaining PHP code (CodeIgniter framework) across the portal's controllers, models, and views.
- Fixing bugs and handling day-to-day support tickets/issues reported by users.
- Building small to medium features and admin reports (working with MySQL, forms, file uploads, and PDF/Excel exports).
- Testing changes carefully before deployment and helping keep the application stable.
- Learning and applying secure coding practices (input validation, safe file uploads, preventing common vulnerabilities like SQL injection and XSS) under senior guidance.
- Working with HTML, CSS, JavaScript, and MySQL alongside PHP for full front-to-back fixes.
- Using Git for version control and following our code review process.
- Gradually taking on more ownership as you get familiar with the codebase.

## What we're looking for

- 0–2 years of experience with PHP (internships, academic projects, or freelance work count).
- Basic understanding of PHP and MySQL fundamentals — variables, functions, loops, queries, joins.
- Familiarity with any PHP framework is a plus (CodeIgniter preferred, but Laravel/others okay).
- Working knowledge of HTML, CSS, and JavaScript.
- Understanding of Git/version control basics.
- Willingness to learn, ask questions, and work on an existing codebase (not just build from scratch).
- Good communication skills and reliability — this is an onsite, team-based role.

## Nice to have

- Any exposure to CodeIgniter specifically.
- Basic awareness of web security concepts (SQL injection, XSS).
- Experience with PDF/Excel generation libraries or admin dashboards/reporting tools.
